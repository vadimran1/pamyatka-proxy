Что умеет

Сделано для тех, кто играет за полицию, прокуратуру, адвокатов — и для всех, кто не хочет листать форум посреди ситуации.

Мгновенный поиск

По номеру («УК 47»), по названию или по тексту. Санкции подсвечены, есть краткий пересказ каждой статьи.

Понимает сленг

«Угнал тачку», «замочил чела», «приняли бухим» — помощник переведёт на язык закона и найдёт статью. Без интернета.

Нейросети ПОДПИСКА

Gemini и Grok объясняют найденные статьи простыми словами. Отвечают только по законам сервера — ничего не выдумывают.

Памятки

Порядок задержания с временем и ссылками на статьи, шпаргалка сотруднику, легальные маски и оружие.

Поверх игры

Горячая клавиша показывает и прячет окно, режим «поверх всех окон», скрытие от записи экрана и стримов.

Голосом

Нажмите кнопку и спросите вслух — распознавание работает прямо на компьютере, без отправки звука куда-либо.

Как выглядит

Тёмное стекло, шесть цветовых тем и свой цвет, всё растёт вместе с окном.

Вопросы

Это официальная программа RMRP?

Нет. Это фанатский проект, он не связан с администрацией сервера. Законы взяты из открытого раздела форума и обновляются вместе с ним. Если формулировка важна — сверяйтесь с форумом.

Windows пишет «Система Windows защитила ваш компьютер»

Так Windows реагирует на любую программу без платной цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае». Программа скачивается только с этого сайта и сервера обновлений автора.

Зачем вход через Discord?

Чтобы у каждого был аккаунт: для подписки, поддержки и чтобы автор видел, сколько людей пользуются Памяткой. Программа получает только ник, аватар и номер аккаунта Discord — ни пароля, ни переписки, ни списка друзей.

Как работает подписка?

Оплата разовая, на 30 дней — картой или кошельком ЮMoney. Автоматических списаний нет: закончилась — продлеваете, если нужно. Подписка включается сама в течение минуты после оплаты.

Работает без интернета?

Законы, поиск, помощник и голос — да. Интернет нужен для нейросетей, обновлений и входа раз в три месяца.
