ПРОКЛАДКА НА VERCEL — по шагам
================================

Что это
-------
Маленький сервер, который держит ключ к нейросети у себя. Программа
шлёт ему вопрос, он добавляет ключ и спрашивает Gemini или DeepSeek.
В программе ключа нет вообще — доставать из exe нечего.


ШАГ 1. Свой репозиторий для прокладки
--------------------------------------
Заведите на GitHub ОТДЕЛЬНЫЙ репозиторий, например pamyatka-proxy.
Не кладите прокладку в репозиторий с обновлениями: там публичные
файлы, а тут нужен порядок с переменными.

Залейте туда содержимое этой папки:
    api/ask.py
    vercel.json


ШАГ 2. Подключить Vercel
-------------------------
1. vercel.com, войти через GitHub
2. Add New -> Project -> выбрать репозиторий pamyatka-proxy
3. Framework Preset: Other. Ничего настраивать не нужно
4. Deploy


ШАГ 3. Вписать ключ
--------------------
В проекте: Settings -> Environment Variables. Добавить:

    PAMYATKA_PROVIDER   gemini        какая сеть отвечает сейчас
    PAMYATKA_KEY_GEMINI     ключ от Gemini
    PAMYATKA_KEY_DEEPSEEK   ключ от DeepSeek

Можно задать оба ключа сразу — прокладка возьмёт тот, что подходит
выбранной сети. Переключение между ними = поменять одну строчку
PAMYATKA_PROVIDER на gemini или deepseek и нажать Redeploy.

Если сеть одна, можно обойтись общим именем PAMYATKA_KEY.

Необязательно:
    PAMYATKA_MODEL      имя модели, если не устраивает обычная
    PAMYATKA_SECRET     слово доступа
    PAMYATKA_RATE       сколько вопросов с адреса за 10 минут (по умолч. 20)

После добавления переменных нажмите Redeploy — иначе они не подхватятся.


ШАГ 4. Проверить
-----------------
Откройте в браузере:
    https://ваш-проект.vercel.app/ask

Должно ответить примерно так:
    {"ok": true, "provider": "gemini", "key": true}

Поле "keys" покажет, какие ключи видит сервер, например ["gemini"].
Если "key": false — переменная не подхватилась, сделайте Redeploy.


ШАГ 5. Включить у пользователей
--------------------------------
В «Выпуск обновления»:
    - галочка «Отвечает нейросеть»
    - кнопка «Прокладка»
    - адрес:  https://ваш-проект.vercel.app
      (без /ask на конце — программа добавит сама)
    - Выпустить обновление

У всех применится при следующем запуске.


ЧТО ВАЖНО ЗНАТЬ
===============

Ограничение частоты работает частично
    Vercel поднимает и гасит экземпляры, а счётчик живёт в памяти
    экземпляра. Резкие всплески он сгладит, но жёстким лимитом не
    является. Поэтому:
      - на Gemini держите бесплатный тариф: он сам ограничен
      - на DeepSeek не держите на счету много денег

Слово доступа бессмысленно раздавать всем
    Адрес прокладки уезжает в aiconfig.json, а он лежит в публичном
    репозитории. Значит всё, что там есть, публично. Слово доступа
    оставьте себе — пригодится, если надо будет быстро закрыть
    прокладку, не трогая сервер.

Если правите промт
    Промт лежит в ai.py программы. Поправили — запустите
    make_vercel.py заново и перезалейте api/ask.py, иначе сервер
    останется со старым промтом.

Бесплатный тариф Vercel
    Для личного пользования его хватает с запасом. Коммерческое
    использование на бесплатном тарифе у них запрещено — для
    справочника по игре это не проблема.
